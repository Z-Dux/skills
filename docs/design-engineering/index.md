# Design Engineering Skills Collection

By [Emil Kowalski](https://emilkowal.ski) (ex-Vercel, Linear, creator of Sonner).

A curated suite of 19 AI agent skills for designers and frontend engineers to build high-craft user interfaces, fluid animations, and production-ready interactions.
