# Frontend & Interface Design Domain

This domain unifies the industry's two premier anti-slop frontend and interface design frameworks for AI coding agents:

1. **[Taste Skill (`design-taste-frontend`)](./taste-skill.md)**: Web art direction, authentic company websites (at the level of figma.com and x.ai), the 9 House Rules, and real-browser visual gate checking.
2. **[Impeccable (`impeccable`)](./impeccable.md)**: The 24-verb design steering vocabulary (`bolder`, `quieter`, `typeset`, `layout`, `polish`), UX critique scoring, technical audits, and the Craft Floor.
